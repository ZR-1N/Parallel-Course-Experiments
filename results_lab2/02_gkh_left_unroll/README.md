# 02_gkh_left_unroll

## 版本说明

- 仅优化 gkh.cpp 中的 apply_left_rows。
- 利用 Matrix 行主序连续存储，将 Matrix::at() 访问改为行指针访问。
- 对行旋转循环进行 4 路手动展开。
- apply_right_cols 保持原始实现。
- 编译选项：-O2
- 随机种子：20260409

## 运行命令

bash test.sh 1 1 1 -O O2 -s 20260409

## 实验结果

- 通过样例数：5 / 5
- 总上二对角化耗时：8756.41 ms
- 总 GKH 迭代耗时：25197.0 ms

## 与 baseline 对比

当前 baseline 结果为：

- 总上二对角化耗时：10342.5 ms
- 总 GKH 迭代耗时：41470.2 ms

本版本相对 baseline：

- GKH 迭代耗时由 41470.2 ms 降至 25197.0 ms。
- GKH 阶段加速比约为 1.65x。
- 上二对角化阶段未做代码修改，其耗时变化主要来自服务器运行波动。

## 分析

本版本是 GKH 阶段较稳定、有效的优化版本。

主要原因是 apply_left_rows 中两行数据在行主序存储下连续访问，使用行指针可以减少 Matrix::at() 的重复下标计算。4 路循环展开降低了循环控制开销，并增加了编译器在 -O2 下进行指令调度和潜在自动向量化的空间。

apply_right_cols 保持原始实现，因为列旋转在行主序矩阵中局部性较差。此前尝试对 apply_right_cols 进行显式 NEON 或手动展开，未稳定带来收益，甚至可能由于访存模式和额外指令开销导致性能下降。
